# Package manager

This project uses `pnpm`. Never use `npm` or `npx`

# Workflow

Ask clarifying questions before starting an implementation if you already know you'll need the answer to proceed correctly. Once you start editing code for a task, keep going without pausing to check in or ask for confirmation - only stop if you hit something you genuinely need the user's input on (an ambiguous requirement discovered mid-task, a destructive/irreversible action, or a blocker you can't resolve on your own).
